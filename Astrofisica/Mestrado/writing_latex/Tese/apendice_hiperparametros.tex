\chapter{Hiperparâmetros dos classificadores}
\label{ap:hiperparametros}

Este apêndice documenta os hiperparâmetros utilizados no treinamento dos classificadores (Regressão Logística, Random Forest, XGBoost, CatBoost) descritos no Capítulo 4. Os valores foram fixados nos \textit{scripts} \texttt{train\_model.py} e \texttt{reanalise\_banca.py} e utilizados em todos os experimentos, sem busca em grade nem validação cruzada para seleção de hiperparâmetros. Para reprodutibilidade, as sementes aleatórias são fixas: 42 nos modelos finais e, em cada repetição da validação cruzada, a semente daquela repetição. Em todos os modelos, valores ausentes são imputados pela mediana do treino (\texttt{SimpleImputer}).

\textbf{Regressão Logística:}
\begin{itemize}
	\item Regularização: Ridge (\(\ell_2\)), valor padrão do scikit-learn (\texttt{penalty='l2'}).
	\item Força da regularização: \(C = 1{,}0\) (valor padrão).
	\item Solver: \texttt{lbfgs} (padrão para regularização \(\ell_2\)).
	\item \texttt{max\_iter}: 1000.
	\item \texttt{class\_weight}: \texttt{balanced}.
	\item Pré-processamento: padronização das \textit{features} (\texttt{StandardScaler}, média zero e desvio unitário).
	\item \texttt{random\_state}: 42.
\end{itemize}

\textbf{Random Forest:}
\begin{itemize}
	\item \texttt{n\_estimators}: 100.
	\item \texttt{max\_depth}: 10.
	\item \texttt{min\_samples\_split}: 5.
	\item \texttt{min\_samples\_leaf}: 2.
	\item \texttt{class\_weight}: \texttt{balanced}.
	\item \texttt{random\_state}: 42.
\end{itemize}

\textbf{XGBoost:}
\begin{itemize}
	\item \texttt{n\_estimators}: 100.
	\item \texttt{max\_depth}: 6.
	\item \texttt{learning\_rate}: 0,1.
	\item \texttt{subsample}: 0,8.
	\item \texttt{colsample\_bytree}: 0,8.
	\item Ponderação de classes: nenhuma (\texttt{scale\_pos\_weight} no valor padrão, 1). O XGBoost não corrige o desbalanceamento por si só; a ponderação foi dispensada porque o conjunto é aproximadamente equilibrado (47\,\% de positivas).
	\item \texttt{random\_state}: 42.
	\item \texttt{eval\_metric}: \texttt{logloss}.
\end{itemize}

\textbf{CatBoost:}
\begin{itemize}
	\item \texttt{iterations}: 100.
	\item \texttt{depth}: 6.
	\item \texttt{learning\_rate}: 0,1.
	\item \texttt{auto\_class\_weights}: \texttt{Balanced}.
	\item \texttt{random\_state}: 42.
\end{itemize}

Não foi utilizada busca em grade (\textit{grid search}) nem validação cruzada para escolha desses hiperparâmetros; os valores acima correspondem a uma configuração de referência fixa, mantida em todos os experimentos para permitir uma comparação justa entre eles, variando-se apenas o conjunto de \textit{features}. Em trabalhos futuros, os hiperparâmetros podem ser ajustados por validação cruzada aninhada no conjunto de desenvolvimento, mantendo o conjunto de teste reservado.
