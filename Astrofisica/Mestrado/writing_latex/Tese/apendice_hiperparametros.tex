\chapter{Hiperparâmetros dos classificadores}
\label{ap:hiperparametros}

Este apêndice documenta os hiperparâmetros utilizados no treinamento dos classificadores (Regressão Logística, Random Forest, XGBoost, CatBoost) descritos no Capítulo 4. Os valores foram fixados no \textit{script} \texttt{train\_model.py} e utilizados em todos os experimentos, sem busca em grade nem validação cruzada para seleção de hiperparâmetros; a semente aleatória (\texttt{random\_state}=42) foi mantida para reprodutibilidade.

\textbf{Regressão Logística:}
\begin{itemize}
	\item Regularização: Ridge (\(\ell_2\)), valor padrão do scikit-learn (\texttt{penalty='l2'}).
	\item Força da regularização: \(C = 1{,}0\) (valor padrão).
	\item Solver: \texttt{lbfgs} (padrão para regularização \(\ell_2\)).
	\item \texttt{max\_iter}: 1000.
	\item \texttt{class\_weight}: \texttt{balanced}.
	\item \texttt{random\_state}: 42.
\end{itemize}

\textbf{Random Forest:}
\begin{itemize}
	\item \texttt{n\_estimators}: 100.
	\item \texttt{max\_depth}: 10.
	\item \texttt{min\_samples\_split}: 5.
	\item \texttt{min\_samples\_leaf}: 2.
	\item \texttt{class\_weight}: \texttt{balanced}.
	\item \texttt{random\_state}: 42.
\end{itemize}

\textbf{XGBoost:}
\begin{itemize}
	\item \texttt{n\_estimators}: 100.
	\item \texttt{max\_depth}: 6.
	\item \texttt{learning\_rate}: 0,1.
	\item \texttt{subsample}: 0,8.
	\item \texttt{colsample\_bytree}: 0,8.
	\item Ponderação de classes: utilizada a opção padrão do XGBoost (sem \texttt{scale\_pos\_weight} explícito no \textit{script}; o desbalanceamento é tratado indiretamente pelo algoritmo).
	\item \texttt{random\_state}: 42.
	\item \texttt{use\_label\_encoder}: \texttt{False}; \texttt{eval\_metric}: \texttt{logloss}.
\end{itemize}

\textbf{CatBoost:}
\begin{itemize}
	\item \texttt{iterations}: 100.
	\item \texttt{depth}: 6.
	\item \texttt{learning\_rate}: 0,1.
	\item \texttt{auto\_class\_weights}: \texttt{Balanced}.
	\item \texttt{random\_state}: 42.
\end{itemize}

Não foi utilizada busca em grade (\textit{grid search}) nem validação cruzada para escolha desses hiperparâmetros; os valores acima correspondem a uma configuração \textit{baseline} fixa, mantida em todos os experimentos para permitir uma comparação justa entre eles, variando-se apenas o conjunto de \textit{features} e a composição do conjunto de teste. Para trabalhos futuros, pode-se explorar validação cruzada estratificada com otimização de F1-score ou AUC-ROC para refinar os hiperparâmetros.
