# Astrofísica

Da iniciação científica na UFRJ ao mestrado no Observatório Nacional — em ordem
cronológica, a evolução do mesmo problema: **medir o Sistema Solar através de
ocultações estelares** (a estrela pisca; no piscar está o tamanho do objeto).

| Pasta | Fase | Conteúdo |
|---|---|---|
| [`Projetos_Iniciais/`](./Projetos_Iniciais/) | Graduação | Primeiros ajustes de curva de luz "na mão": χ², resíduos, chute de parâmetros |
| [`Projetos_Estatística/`](./Projetos_Estatística/) | Graduação | Listas e projetos de astroestatística (derivação de Poisson, verossimilhança, bootstrap) |
| [`Mecanica_Celeste/`](./Mecanica_Celeste/) | Graduação/IC | Dinâmica de pequenos corpos (MakeMake), posição e movimento |
| [`e-science/`](./e-science/) | Graduação | Aulas de Python científico |
| [`Exercicios/`](./Exercicios/) | Graduação | Exercícios de curso |
| [`Mestrado/`](./Mestrado/) ⭐ | Mestrado (ON) | **Pipeline de ML para detecção automática de ocultações** — o projeto principal deste repositório |

Contexto da IC: coautoria no artigo *Kilometer-precise Umbriel physical properties
from the multichord stellar occultation on 2020 September 21* (MNRAS).
